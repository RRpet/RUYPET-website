# 第一阶段测试证据（合成图，不是狗狗实拍）

- `comparison.png`：处理前后对比；`before.png` / `after.png`：对应像素原尺寸文件。
- `measurements.json`：只开启背景均匀化与偏色校正的参数及量测。背景候选亮度标准差从 8.66 降至 0.91；受检查的细线、产品色块、半透明纹理、阴影控制区无像素变化。**不是实际狗狗毛发或真实纱料的验证。**
- `example.ruypet.json`：可通过“打开修图项目”导入的完整合成演示项目，含两张原片、可编辑预设、保护笔迹及测试用黑条 LOGO（非 RUYPET 官方标志）。
- `batch-output.zip`：该演示项目实际批量导出的两张 JPG 及处理报告。演示预设还含高光/阴影和单张微调，因此其色值不等于上面的纯背景算法测试输出。
- `workspace.png`：浏览器中的真实双图对照界面截图。
- `icc-orientation.json`：Adobe RGB 兼容 ICC、EXIF=6 测试导出 80×120，和 LittleCMS 转换参考像素最大差异为 1/255。
- `r7-resolution.json`：6960×4640（32,294,400 像素）合成平场的实际 worker 运行尺寸、耗时及透明通道检查；机器负载影响耗时。不是 R7 实拍测试。

以上证据由 `tests/photo-lab.spec.ts` 的当前测试执行生成。真实宠物照片、商品颜色准确性及黑纱等复杂材料仍需用户提供样片并人工验收。
