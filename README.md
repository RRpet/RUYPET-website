# RUYPET DETAIL STUDIO V1

面向 Mac 的本地可视化商品详情页编辑器。中文界面，React + TypeScript + Vite + Konva。无需账号，无云同步，无生成式 AI，不上传原始图片。不包含旧版网站。

## Mac 安装和打开

1. 从 https://nodejs.org 下载并安装 **Node.js 24 LTS** 的 macOS 安装包（按 Mac 芯片选择 Apple Silicon 或 Intel）。只需安装一次。
2. 从 GitHub 仓库点击 **Code → Download ZIP**，解压到文稿等可写目录，保留全部文件。首次安装依赖需要联网。
3. 双击目录中的 **启动.command**。如果 macOS 提示无法验证，确认文件来源后，在“系统设置 → 隐私与安全性”允许打开，或右键“打开”。不要关闭系统安全检查。
4. 终端自动安装锁定版本的依赖并打开浏览器。等待页面出现。如果浏览器打开过早，稍后刷新即可。日常使用只需双击这个文件，不需要输入代码或命令。
5. 使用完成后，先保存项目，再在启动窗口按 **Control+C** 关闭本地服务。窗口关闭后不会继续提供编辑器。

如果提示 5173 端口占用，请先关闭之前启动的本工具窗口，勿关闭不认识的进程。如系统将脚本标为无可执行权限，可在终端进入解压目录执行一次 `chmod +x 启动.command`。本机启动脚本仅监听 127.0.0.1。

## 工作流程

- **导入照片**：批量选择 JPG、PNG、WebP，单张上限 30MB。点击缩略图或拖入画布。图片解码失败会显示错误，原文件始终不改写。
- **编辑**：选中图片或文字，拖动移动、拖动控制点改变大小。右侧输入精确位置、尺寸、透明度；调整图层顺序、复制或删除。双击文字后在右侧编辑内容；可选字体、字号、行距、颜色和对齐。图像拉伸后可点“恢复比例”。
- **裁切**：右侧按原图百分比设置左侧、顶部、宽度和高度；“重置裁切”恢复完整原图。只改变可见区域，不修改照片像素。所有操作均不使用生成式 AI。
- **页面**：默认宽 790px、高 1000px。新增、复制、删除、上下移动页面；每页高度范围 100–10000px。撤销/重做支持最近 60 步，也支持 Command+Z / Command+Shift+Z（输入框内仍使用系统文字撤销）。
- **品牌和模板**：“品牌样式”中设置字体、背景、正文与辅助色、留白和文字层级，添加七页服装模板。模板内容与品牌数据独立。初始黑白灰、Arial 仅为可替换占位配置，**未经确认的样式不代表 RUYPET 品牌最终规范**。Mac 系统字体由浏览器使用；跨机器缺少字体时会回退，交付前请核对。
- **保存**：“保存项目”下载 `.ruypet.json`，包含所有页面、品牌、原始图片的完整数据。请确认浏览器下载成功并妥善备份；项目不自动保存在浏览器缓存，刷新前必须保存。“打开项目”重新导入文件即可继续编辑。素材较多时 JSON 较大，请分项目管理。
- **导出**：“导出检查”选择 PNG/JPG，导出当前页、所有页 ZIP 或按页面顺序拼成长图。固定 790px 宽，画布显示缩放不影响导出。长图高度上限 30000px、总像素上限 2400 万，超出请用 ZIP。导出不包含选框。ZIP 内文件按 01、02 编号。
- **检查**：显示缺图、原图裁切区域低于输出分辨率、文字高度溢出、图层出界警告。缺图会阻止相关导出，其余警告允许人工判断。检查不验证文案真实性、印刷色彩或视觉美观。

## 本地数据与限制

没有邮件、登录、淘宝发布或远程图片服务。浏览器内存负责编辑，项目文件负责长期保存。素材不上传，项目文件含完整原图，请按商品资料的保密要求保管。V1 使用普通栅格导出，不重绘产品颜色、版型、材质、LOGO 或结构。裁切、拉伸、透明度会影响排版展示，应自行确认符合真实产品要求。建议近期版本 Safari / Chrome、桌面宽度至少 1050px。大素材和多页项目会占用内存，导出前保存项目。字体变化后的导出需人工复核。

## 开发与验证

```sh
npm ci
npm run dev
npm run build
npx playwright install chromium
npm run test:e2e
```

`npm run build` 包含 TypeScript 检查。E2E 测试使用 Chromium，验证素材导入、画布编辑、页面/模板、文件保存恢复、PNG/JPG/ZIP/长图尺寸及质量警告。不依赖外部图片 CDN。测试下载目录属于临时结果，不提交到仓库。
